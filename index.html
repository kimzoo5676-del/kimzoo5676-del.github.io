01 / How I Work

데이터를 검토하고 기획을 세운 뒤,
모르는 것은 경험하고 물어보며 성장합니다

기획을 확정하기 전에 데이터를 확인하고 구체화합니다. 모르는 것은 경험하고 물어본 뒤 배웁니다. 배운 것은 공유하며 함께 나아갑니다.

/ 01

데이터부터 확인합니다

데이터를 확인해야 기능을 구체화할 수 있습니다. 확인하지 않고 구현한 기능은 문제가 생기기 쉽습니다. 가공된 데이터도 다시 한 번 확인하여 오류를 방지합니다.

/ 02

경험하고 배워나갑니다

이론만으로 학습하지 않고 프로젝트에 적용하여 경험해봅니다. EC2 서버에서 명령어를 치며 배포해보고, GitHub Actions나 Jenkins로 배포를 자동화해보며 직접 학습했습니다.

/ 03

새로운 도전을 좋아합니다

첫 프로젝트는 DRF를 활용한 웹 서비스였습니다. 이후 두 번째 프로젝트는 Flutter, Spring Boot, FastAPI를 활용한 앱 서비스였습니다. 개발 환경은 가상환경으로도, Docker로도 세팅해봤습니다. Kubernetes 특강을 들으며 GKE도 사용해보는 등 새로운 것에 도전하였습니다.
